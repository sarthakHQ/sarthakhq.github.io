PHOTOS
======

Every picture on the page lives in this folder. The site loads them by file name.

To use your own photo, save it here with exactly the same file name (replace the old one).
Keep roughly the same shape; the size listed is what the slot is designed for. Bigger is fine,
and anything close in shape works because each slot crops to fit.

If a photo is missing, the page paints a stand-in from the ride, so nothing ever shows up blank.
To rename a file or change its framing, edit the PHOTOS list near the top of the script in index.html.
